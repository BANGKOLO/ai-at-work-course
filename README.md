# AI at Work / L'IA au travail

A free, bilingual (English/French) 28-lesson course on practical AI skills for anyone who uses a computer at work.

- **Start here:** `index.html` — course overview and pricing
- **Lesson site:** `site/index.html` — the course itself (mobile-first, works offline after first load, no signup)
- **Printable workbook:** `workbook/workbook.html`

No personal data is collected. Progress is stored only in your own browser.
