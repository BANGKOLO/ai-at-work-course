Module A — AI Foundations / Fondamentaux de l'IA

English

1. Understanding generative AI — predicts likely text, does not look up facts by default; strengths: drafting/summarising; limits: invented facts, bias.

2. The structured prompt (RCTFC) — Role, Context, Task, Format, Constraints.

3. Confidentiality and compliance — four data classes: Public, Internal, Confidential, Personal.

4. Picking the right AI tool for the job — match the task to a tool category; free/paid tiers change often, check yourself.

Français

1. Comprendre l'IA générative — prédit un texte probable, ne consulte pas une base de faits par défaut ; points forts : rédiger/résumer ; limites : faits inventés, biais.

2. Le prompt structuré (RCTFC) — Rôle, Contexte, Tâche, Format, Contraintes.

3. Confidentialité et conformité — quatre classes de données : Publique, Interne, Confidentielle, Personnelle.

4. Choisir le bon outil d'IA pour la tâche — faire correspondre la tâche à une catégorie d'outil ; les niveaux gratuits/payants changent souvent, à vérifier soi-même.
