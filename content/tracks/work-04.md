# Advanced · Lesson 4

## English

### Title: Claude or ChatGPT? Choosing, and cross-checking with both

**Duration:** 25 minutes

#### Content

You have now worked with both tools. Professionals rarely ask "which one is best?" They ask "which one for *this* task, and when is it worth using both?"

**First filter: what your organisation allows**

The tool approved by your employer, on a business plan, beats any capability difference. If only one is approved, use that one for work data. Use the other only with public or non-sensitive material, if at all.

**Second filter: features, not reputation**

Both tools change every few months, and today's leader on one task may not be the leader next quarter. Choose by the feature you need:

| You need... | Look for... |
|---|---|
| A reusable workspace for recurring work | Claude Projects / ChatGPT Projects |
| A shareable single-task assistant for a team | ChatGPT custom GPTs / Claude shared Projects and Skills |
| Editing a long document with you | ChatGPT Canvas / Claude artifacts |
| Real Word, Excel, PowerPoint files | Both can create files (check your plan) |
| Spreadsheet analysis with code | Both run code on uploaded files |
| A long cited report on a broad question | ChatGPT deep research / Claude Research |
| Access to your email, calendar, drive | Connectors in both (admin approval) |
| Multi-step tasks on websites | ChatGPT agent mode / Claude in Chrome |
| Talking instead of typing | Voice modes in both mobile apps |

**Third filter: run your own test**

Reviews online cannot tell you which tool handles *your* documents and *your* language best. Run a small test once a quarter:
1. Pick three real tasks you do often (for example: a French client email, a contract question, a spreadsheet summary).
2. Give both tools the **identical** prompt and files.
3. Score each output on what matters to you: accuracy (number of errors), edits needed, time.
4. Keep the scores in a simple table. Choose per task, not overall.

**Cross-checking: a second opinion on high-stakes work**

For work where an error is expensive (a figure going to the board, a contract interpretation, a public statement), use the second tool as a reviewer:

> Below is a draft produced by another AI assistant, and the source material it was based on.
> Check the draft against the sources. List: (1) statements not supported by the sources, (2) numbers that do not match, (3) important points from the sources that the draft omits.
> Do not rewrite the draft.

Why this works: the two models were trained differently and tend to make different mistakes. When both agree, that is not proof (they can share an error), but disagreements point you straight to what needs a human check.

**When to stop switching**

Constant tool-hopping wastes the setup you have done (profile, memory, Projects, GPTs). Pick a **primary** tool for daily work, and use the other deliberately: for its specific feature, or as a cross-checker.

#### Worked example

A compliance officer drafts an internal summary of a new regulation with her primary tool. Before circulation, she asks the second tool to check the draft against the regulation text. It flags that the draft says "must report within 30 days" where the regulation says "30 business days". She confirms in the source and corrects it. Two minutes of cross-checking prevented a company-wide instruction with the wrong deadline.

#### Activity

1. Pick three real tasks and run the identical-prompt test in both tools.
2. Score accuracy, edits needed and time in a table.
3. Decide your primary tool for each task, and choose one task type where you will always cross-check.

## Français

### Titre : Claude ou ChatGPT ? Choisir, et contre-vérifier avec les deux

**Durée :** 25 minutes

#### Contenu

Vous avez maintenant travaillé avec les deux outils. Les professionnels se demandent rarement « lequel est le meilleur ? ». Ils se demandent « lequel pour *cette* tâche, et quand vaut-il la peine d'utiliser les deux ? »

**Premier filtre : ce que votre organisation autorise**

L'outil approuvé par votre employeur, sur une offre professionnelle, l'emporte sur toute différence de capacités. Si un seul est approuvé, utilisez-le pour les données de travail. N'utilisez l'autre qu'avec des contenus publics ou non sensibles, voire pas du tout.

**Deuxième filtre : les fonctions, pas la réputation**

Les deux outils évoluent tous les quelques mois, et le meilleur d'aujourd'hui sur une tâche ne le sera peut-être plus au trimestre prochain. Choisissez selon la fonction dont vous avez besoin :

| Vous avez besoin de... | Cherchez... |
|---|---|
| Un espace réutilisable pour un travail récurrent | Projets Claude / Projets ChatGPT |
| Un assistant mono-tâche partageable en équipe | GPT personnalisés ChatGPT / Projets partagés et Skills Claude |
| Réviser un long document à deux | Canvas ChatGPT / artefacts Claude |
| De vrais fichiers Word, Excel, PowerPoint | Les deux créent des fichiers (selon l'offre) |
| Analyser un tableur avec du code | Les deux exécutent du code sur les fichiers importés |
| Un long rapport sourcé sur une vaste question | Recherche approfondie ChatGPT / Research Claude |
| Accéder à vos emails, agenda, Drive | Connecteurs dans les deux (accord de l'administrateur) |
| Des tâches en plusieurs étapes sur des sites web | Mode agent ChatGPT / Claude in Chrome |
| Parler au lieu de taper | Modes vocaux des deux applications mobiles |

**Troisième filtre : votre propre test**

Les avis en ligne ne peuvent pas vous dire quel outil traite le mieux *vos* documents et *votre* langue. Faites un petit test chaque trimestre :
1. Choisissez trois vraies tâches fréquentes (par exemple : un email client en français, une question contractuelle, une synthèse de tableur).
2. Donnez aux deux outils le **même** prompt et les mêmes fichiers.
3. Notez chaque résultat sur ce qui compte pour vous : exactitude (nombre d'erreurs), corrections nécessaires, temps.
4. Gardez les notes dans un tableau simple. Choisissez tâche par tâche, pas globalement.

**La contre-vérification : un second avis pour les travaux à enjeu**

Pour un travail où l'erreur coûte cher (un chiffre pour le conseil, l'interprétation d'un contrat, une déclaration publique), utilisez le second outil comme relecteur :

> Ci-dessous, un brouillon produit par un autre assistant d'IA, et les sources sur lesquelles il s'appuie.
> Vérifie le brouillon au regard des sources. Liste : (1) les affirmations non appuyées par les sources, (2) les chiffres qui ne concordent pas, (3) les points importants des sources que le brouillon omet.
> Ne réécris pas le brouillon.

Pourquoi cela marche : les deux modèles ont été entraînés différemment et ont tendance à faire des erreurs différentes. Quand ils sont d'accord, ce n'est pas une preuve (ils peuvent partager une erreur), mais leurs désaccords vous montrent directement ce qui mérite une vérification humaine.

**Quand arrêter de changer d'outil**

Passer sans cesse d'un outil à l'autre gaspille la configuration déjà faite (profil, mémoire, Projets, GPT). Choisissez un outil **principal** pour le quotidien, et utilisez l'autre délibérément : pour une fonction précise, ou comme contre-vérificateur.

#### Exemple détaillé

Une responsable conformité rédige une synthèse interne d'une nouvelle réglementation avec son outil principal. Avant diffusion, elle demande au second outil de vérifier le brouillon par rapport au texte réglementaire. Il signale que le brouillon dit « déclarer sous 30 jours » là où la réglementation dit « 30 jours ouvrables ». Elle confirme dans la source et corrige. Deux minutes de contre-vérification ont évité une consigne à toute l'entreprise avec un mauvais délai.

#### Activité

1. Choisissez trois vraies tâches et faites le test du prompt identique dans les deux outils.
2. Notez exactitude, corrections nécessaires et temps dans un tableau.
3. Décidez de votre outil principal pour chaque tâche, et d'un type de tâche pour lequel vous contre-vérifierez toujours.
